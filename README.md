# Biblioteca-segunda-unidad
Práctica segunda unidad - Programación avanzada

# 1. Requisitos del sistema
* Sistema operativo: Windows, Linux o macOS.
* Python 3.9 o superior instalado en el sistema.

# 2. Verificación de python y tkinter
* Abre la terminal
* Escribe el comando: "python -m tkinter"
* Si se abre una pequeña ventana, el entorno está correctamente configurado.

# 3. Archivos del proyecto
* Verifique que en la carpeta del proyecto se encuentren los siguientes elementos:
* Archivos .py del programa (por ejemplo: main.py, data_manager.py, etc.)
* Archivos .json de datos: libros.json, usuarios.json, prestamos.json, devoluciones.json
* Cualquier carpeta adicional entregada (como data).

Si los archivos JSON no existen, el programa los creará automáticamente al ejecutarse por primera vez.

# 4. Ejecutar el programa
* Descargar la carpeta con todos los archivos ya incluidos dentro de ella
* Abrir el directorio de la carpeta
* ejecutar el archivo biblioteca1.py
